# Coleccion de 42 prototipos educativos de IA

Docente: Julian Rene Muñoz Burbano.

Cada carpeta contiene un notebook, frontend Streamlit, API FastAPI, persistencia MongoDB, baseline ML, tests y guia Anaconda. **Son esqueletos funcionales didacticos, no 42 soluciones de dominio terminadas**. Consulte cada README para limites e instrucciones.

## Actualización de datasets
El catálogo global está en `CATALOGO_DATASETS.csv`; revisa la ficha y licencia de cada fuente antes de usarla. El proyecto de reconstrucción de frontend entrena en su notebook un índice visual con una muestra en streaming de WebSight. Los demás prototipos mantienen sus propias instrucciones de descarga y entrenamiento.
